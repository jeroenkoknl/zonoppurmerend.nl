# Zonoppurmerend.nl Wordpress Site

De webside [zonoppurmerend.nl](https://www.zonoppurmerend.nl/) is gemaakt met behulp van Wordpress. Hierbij is gebruik gemaakt van het [Eco Press](https://themeforest.net/item/eco-press-nature-ecology-ngo-wordpress-theme/17419950) theme. 

## Licentie

Zon op Purmerend Coöperatie U.A. heeft een licentie gekocht van het Eco Press theme. Deze licentie is toegankelijk via het Envato account van de coöperatie. Via dit account kunnen updates gedownload worden.

## Aanpassing

Om de site naar behoren te laten werken, is [functions.php](./wp-content/themes/eco-press/functions.php) aangepast. Nadat het Eco Press theme is geupdate, moet deze aanpassing opnieuw worden toegepast.

De specifieke aanpassing is op regel 57:

```
			'Lato:300,300italic,700,700italic|Lato', 
```
